# OmniCam keyboard shortcuts and controls

Shortcuts only apply while the OmniCam viewport or timeline is active. They do
not replace normal typing shortcuts when an input field is focused.

## Camera navigation

| Control | Action |
|---|---|
| Left mouse drag | Orbit the camera |
| Shift + left mouse drag | Pan the camera |
| Mouse wheel | Dolly forward or backward |
| Double-click viewport | Set the camera target |
| `W`, `A`, `S`, `D` | Fly forward, left, backward, and right |
| `Q`, `E` | Fly down and up |
| `F` | Frame the selected object or camera target |

## Animation and playback

| Shortcut | Action |
|---|---|
| `I` | Insert or replace a keyframe at the current frame |
| `Space` | Play or stop the timeline |
| Left / Right Arrow | Previous or next frame |
| Up / Down Arrow | Previous or next keyframe |
| Home / End | First or last frame |
| `[` / `]` | Set the playback range start or end |
| Delete / Backspace | Delete the selected keyframe or object |
| `Ctrl/Cmd + C` | Copy the selected keyframe |
| `Ctrl/Cmd + V` | Paste a keyframe at the playhead |

## Editing

| Shortcut | Action |
|---|---|
| `W` | Translation gizmo |
| `E` | Rotation gizmo |
| `R` | Scale gizmo |
| `Ctrl/Cmd + Z` | Undo |
| `Ctrl/Cmd + Shift + Z` | Redo |
| Escape | Close a menu or leave the current key edit |

When using `W`, `E`, or `R`, the result depends on whether the viewport is in
camera navigation or object editing mode.

## Timeline and curve editor

| Control | Action |
|---|---|
| Click or drag the timeline | Scrub through frames |
| Drag a keyframe | Move it in time |
| Shift + click | Add a keyframe to the selection |
| Shift + drag empty timeline space | Box-select keyframes |
| Alt + drag a keyframe | Duplicate and move it |
| Mouse wheel over timeline | Zoom the timeline |
| Middle mouse or Alt + drag | Pan the timeline or curve editor |
| Drag a curve point | Change its time or value |
| Drag a tangent handle | Adjust Bézier easing |
| Right-click | Open actions for the current area |

## Useful buttons

- **Auto Key** records camera or object changes at the current frame.
- **Camera View** opens the camera preview strip.
- **Record** creates the playblast used as a motion reference.
- **Reset Camera** restores the default camera position.
- **Clear Caches** releases loaded media and viewport resources.
